# LearnThinking

AI ハーネスのセッションログから、記録済みの思考・推論要約に頻出する英単語を集計して学べる、日本語の静的 Web アプリです。

## 主な機能

- 複数ファイル・フォルダーの読み込み、ドラッグ＆ドロップ
- **Codex** の `response_item` 内の `reasoning` と `event_msg` 内の推論要約
- **Claude Code** の `assistant.message.content` 内の `thinking` ブロック
- **Gemini CLI** の `messages[].thoughts`（記録済みの思考要約）
- **OpenCode** の `reasoning` 部分、および同様の構造を持つ汎用ログ
- `.json` / `.jsonl` / `.txt` / `.md` を読み込み（テキストファイルは全体を思考本文として扱います）
- 英単語の集計と頻度順位、日本語の簡易辞書、原文中の使用例
- 学習状態の記録、間隔を空けたフラッシュカードによる復習
- 単語帳の CSV 書き出し、学習データの JSON バックアップ・復元
- データの保存はブラウザの `localStorage` のみ（外部 API / サーバーなし）

## 使い方

Python などの静的ファイルサーバーを使って `index.html` を開きます。

```bash
python3 -m http.server 4173
```

ブラウザで <http://localhost:4173> を開き、**ログを追加**からセッションファイルを選択します。初回は明示的にサンプルと示した学習用データが入っています。実際のログを取り込む際、サンプルは自動的に入れ替わります。

一般的な保存先の例：

- Codex: `~/.codex/sessions/` の JSONL
- Claude Code: `~/.claude/projects/` の JSONL
- Gemini CLI: `~/.gemini/tmp/<project_hash>/chats/` の JSON / JSONL

各ハーネスのバージョンや設定によって保存形式・思考の記録範囲は変わります。**平文の思考や要約がファイルに含まれていない場合、その内容を復元することはできません。** 暗号化された思考は読み取りません。また、ユーザー発言、ツールの入出力、アシスタントの通常の回答は頻度集計から除外しています。

## プライバシー

選択したファイルはブラウザ内でのみ読み込み、ネットワークへ送信しません。読み込み後は **単語ごとの集計・短い例文・学習履歴** をブラウザ内に保持し、セッション本文全体は保存しません。短い例文に機密情報が含まれるおそれがあるため、共有端末やバックアップファイルの扱いに注意してください。「設定とデータ」から全削除できます。

## 開発・検証

追加パッケージは不要です。テストは Node.js 20 以降で実行できます。

```bash
npm test
```

## 公開

静的サイトを GitHub Pages で公開できるよう `.github/workflows/pages.yml` を同梱しています。リポジトリの Settings → Pages → Build and deployment で **GitHub Actions** を選択すると、`main` への更新を自動公開します。

## 注意点

初期辞書はよく登場する単語の簡易訳で、辞書未登録の単語は自分で意味を入力できます。語形の正規化は簡易的な方式です。保存容量は利用するブラウザに依存します。35 MBを超えるファイルは読み込み対象外です。
